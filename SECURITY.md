# Reporting a security issue

Use this repository's **Security > Report a vulnerability** form for issues
that could expose student data or cause an unintended registration change.
If private reporting is unavailable, open an issue asking for a private
contact route and omit exploit details and student data.

Include the extension and Chrome versions, the affected behavior, and a
reproduction with fabricated course data where possible. Do not include
passwords, passkeys, cookies, tokens, student identifiers, or private page HTML.

Only the latest release receives fixes. A seat alert or a submitted request
does not establish enrollment; verify the outcome in USC Web Registration.
